# Imagens-fonte dos quadros

Salve nesta pasta as dez imagens anexadas ao chat, mantendo a ordem abaixo. PNG, JPG e JPEG são aceitos; o nome deve começar com o número indicado.

1. `01-feliz-datas` — Feliz Dia da Mulher / Feliz Dia das Crianças
2. `02-happy-nation` — Lula na multidão com “HAPPY NATION”
3. `03-me-respeita` — “ME RESPEITA” / “CRÉU”
4. `04-pergunta` — entrevistado com ponto de interrogação
5. `05-rachadinha-tres-porcento` — Renan Santos / Flávio rachadinha 3%
6. `06-sacos-lula-flavio` — sacos “LULA” e “FLAVIO”
7. `07-mestre-dos-bagos` — “Mestre dos BAGOS!”
8. `08-bolsonaro-joinha` — Bolsonaro sentado fazendo joinha
9. `09-um-pau` — cédula de “1 PAU”
10. `10-tweet-autodeclaracao` — captura dos dois tweets

As fontes são preservadas. As texturas de runtime serão preparadas mecanicamente com proporção mantida, sem recriar texto ou rostos por IA.
